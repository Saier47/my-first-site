PostgreSQL 这条不是从接口读的 —— 是直接连数据库查的，用来交叉印证接口真的写进去了
查询语句
SELECT id, name, day_of_week, start_time, end_time, location, created_at
  FROM courses
 WHERE id = 'c_muy5tskqt8wm3a';

怎么证明"数据库真的多了一行"：
· courses 行数：Day 16 灌种子后是 10 行 → 现在 12 行（今天通过接口写进 2 行测试数据）
· 这条 c_muy5tskqt8wm3a 的 id 和 created_at 都不是请求里给的 —— 请求只发了 5 个业务字段，id 是后端生成的、时间戳是数据库生成的。
· 而且它和接口返回的 JSON 逐字一致（对照上一张图）—— 两边是两条独立的路（一个走 HTTP 接口、一个直连数据库）， 结论一样，才叫验证过。
