## 3. 🔑 今天要掌握的那句：防了哪一种重复提交？

> **「你防了哪一种重复提交或错误输入？怎么测的？」**

### 防了两种重复

| | 防什么 | 返回 |
|---|---|---|
| **线 1 · id 冲突** | 同一个 `id` 已经存在 | `409 CONFLICT` |
| **线 2 · 内容查重** | 内容等价的记录已经存在 | `409 CONFLICT` + 具体人话 |

**"内容等价"的判定键**：

| 表 | 查重键 | 为什么这么选 |
|---|---|---|
| `courses` | `name` + `day_of_week` + `start_time` | **不含 location** —— 换个教室重录，还是同一节课 |
| `ddls` | `title` + `due_date` | **不含 note** —— 备注改了也还是同一件事 |

### ⚠️ 为什么"线 2"才是真防线（这是今天最值钱的一条）

> `id` 是前端 `newId()` **每次随机生成**的 —— 用户连点两次保存，会生成**两个不同的 id**。
> 所以只做「线 1」**根本拦不住"手滑连点"**，是纸糊的防线。

### 加上第三层：数据库唯一约束

应用层的查重是"查完再写"，**查完到写入之间有个时间窗**，两个并发请求可能都查到"没有"然后都往里写。
所以线上还有一道**数据库唯一约束**兜底（`db/alter-day18.sql`）：

```sql
courses: UNIQUE (name, day_of_week, start_time)
ddls   : UNIQUE (title, due_date)
```

命中时接口返回的仍是 **`409`（不是 500）** —— 因为"重复"不是服务出错。

> **应用层判断是"软"的，数据库约束是"硬"的。**

### 还防了一大类错误输入

缺字段 / 类型错（`day_of_week` 传字符串 `"3"` 也拒）/ 超长 / 时间格式错 /
结束早于开始 / 日期不存在（`2026-02-30`）→ 全部 `400` + **中文人话**，并且说清**缺了什么**。

## 4. 清单要的三条测试命令

### ① 正常写入

```bash
curl -X POST "https://my-first-site-d0g3re4p71560e327-1500310885.ap-shanghai.app.tcloudbase.com/api/courses" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试课","day_of_week":1,"start_time":"08:00","end_time":"09:40","location":"三教 201"}'
```
→ 期望：`200` + `{"ok":true,"data":{"id":"c_xxx",...}}`（`id` 由后端生成）

### ② 重复提交（同样的内容再发一次）

```bash
curl -X POST "https://my-first-site-d0g3re4p71560e327-1500310885.ap-shanghai.app.tcloudbase.com/api/courses" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试课","day_of_week":1,"start_time":"08:00","end_time":"09:40","location":"换个教室"}'
```
→ 期望：`409` + `{"ok":false,"error":{"code":"CONFLICT","message":"这门课已经在课表里了（测试课 · 周一 08:00），不用重复添加"}}`

> 注意：**换了 location 也算重复** —— 因为查重键里故意不含 location。

### ③ 缺必填字段

```bash
curl -X POST "https://my-first-site-d0g3re4p71560e327-1500310885.ap-shanghai.app.tcloudbase.com/api/courses" \
  -H "Content-Type: application/json" \
  -d '{"name":"只有名字"}'
```
→ 期望：`400` + `{"ok":false,"error":{"code":"VALIDATION_FAILED","message":"缺少必填字段 day_of_week（星期几），应为 1 到 7 的整数（1 = 周一）"}}`

### ④ 数据库 select 验证

在项目文件夹里跑：

```bash
bash db/run-sql.sh  # 需要临时建个查询文件，或者直接用命令行：
```

或直接用 SQL（`tcb db execute` / 控制台 SQL 编辑器都行）：

