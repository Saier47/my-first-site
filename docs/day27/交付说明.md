## 🔴 演练中真实撞上的一个卡点（**最高优先级的候选**）

**保存 DDL 时，「截止时间」（`due_time`）是必填的，只填日期会被挡住。**

```js
function validateDdl(data) {
  if (!data.title)    return '请填事项名称';
  if (!data.due_date) return '请选截止日期';
  if (!data.due_time) return '请填截止时间';   // ← 卡在这里
  return null;
}
```

**我当时的操作**：填标题「手机测试作业」+ 日期 2026-10-20 → 点保存
**结果**：弹层没关，红字提示「**请填截止时间**」，DDL 没加进去

**为什么可能是真问题**：
- 用户常常只知道「**明天交**」，不知道几点
- 手机上选时间比选日期更麻烦（要再点开一个时间选择器）
- 卡住的时候**没有出路提示**（"不知道几点的话可以留空"）

> **但要等真人验证再动手**：如果他没卡这儿，说明没我想的严重。
