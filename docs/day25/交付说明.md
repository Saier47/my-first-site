## 一、今天要掌握的那个问题

> **你故意弄坏哪一项来验证 Skill 不会虚报通过？**

**答案：第【4】项「线上前端 == 本地前端」。**

做法：**往本地 `app.js` 末尾加了一行、但不部署** —— 制造「改了但忘了上线」这个最典型的失误。

| 步骤 | 结果 |
|---|---|
| 弄坏前跑 | 第 4 项 ✅ |
| **弄坏后跑** | 第 4 项 **❌ 有 1 个文件线上和本地不一致：`app.js`（本地 55829 字节 / 线上 55736 字节）** |
| 还原后跑 | 第 4 项 ✅ 恢复 |

**为什么挑这一项来弄坏**：

- 它是**唯一一项"页面照样能开、接口照样通"却仍然有问题**的检查
  —— 弄坏之后，前 3 项**全是绿的**，只有第 4 项会红
- 它对应一个**真实会犯的错**：改完忘了部署
- 它**必须报得准**：光说"部署有问题"没用，得说清**哪个文件、差多少**

> 🔑 **为什么非要走这一步**：
> 一个**永远输出 ✅** 的检查，和**真的全绿**，在屏幕上长得一模一样。
> 所以判断一个检查有没有用，不能看它平时绿不绿 ——
> **要看它被弄坏时会不会红、红得准不准。**

## 二、板块① 规划检查项

**设计原则：每一项都必须"真的能失败"。**

| # | 查什么 | 怎么查 | 不合格的典型 |
|---|---|---|---|
| 1 | 公网页面能打开 | HTTP GET，看状态码 + 字节数 + `<title>` | 404 / 空响应 / 错误页 |
| 2 | 打开的是**应用**、不是中间页 | 内容含「这一周」且不含「页面访问提示」 | **HTTP 200 但拿到腾讯云提示页** |
| 3 | 接口活着 | `GET /api/courses` → 200 + `ok:true` | 页面在、数据不在 |
| 4 | ⭐ **线上 == 本地** | 8 个部署文件逐个比对（文本比内容 / 图片比 sha256） | **改了但没部署** |
| 5 | 仓库里没有密钥 | `audit-secrets.py`（8 类规则 + git 全历史） | 密钥进过仓库 |
| 6 | `.env` 被忽略 | `git check-ignore` | 被 `git add -f` 强加过一次 |
| 7 | 工作区干净 | `git status --short` 为空 | 线上跑的是半成品 |
| 8 | 没有没推的提交 | 本地 HEAD == 远端 | 提交了但没推上去 |

**一个细节**：第 2 项是**故意从第 1 项里拆出来的**。
腾讯云的强制提示页**HTTP 状态也是 200** —— 只查状态码会把它当成"部署成功"。

## 四、板块③ 实跑验证

### 4.1 先跑一遍干净的 → 抓出真问题

第一次跑，第【5】项就红了 —— **但那是误报**：

```
❌  扫出 3 条疑似密钥
      ❌ audit-secrets.py [Postgres 连接串带密码] 'postgres://user:password@host 形式'),
      ❌ audit-secrets.py [赋值式 password/secret] 'db_' + 'password = "hunter2secret"',
      ❌ audit-secrets.py [Postgres 连接串带密码] 'DATABASE_URL=postgres://admin:...'
```

**三条全是 `audit-secrets.py` 自己文件里的内容**（规则的说明文字 + 编的自检样本），不是真泄露。

**根因**：`scan_workspace()` 里有一行"跳过自己"，**`scan_git_history()` 忘了加** ——
于是历史扫描把扫描器**自己在 git 历史里的 diff** 当成了泄露。

**这个发现本身很有价值**：一个会误报的检查，用户查两次发现是虚惊，**下次就再也不信它了**。
假阳性比漏报更能毁掉一个检查。

**修法**：
1. `scan_git_history()` 补上跳过自己（并写明取舍：工具文件里真藏密钥的风险 ≪ 天天误报的代价）
2. 把规则说明文字也拆开写（`'postgres' + '://user:...'`），免得它被自己的正则命中

**修完**：自检 8/8 仍全过（说明尺子还是准的），真扫 **0 命中**。

### 4.2 故意弄坏 → 验证它真的会红

见本文第一节。**截图就是这一次的输出**。

### 4.3 还原 → 确认恢复

`git checkout -- app.js` → 字节数回到 55736（= 线上）→ 第 4 项 ✅

### 4.4 收尾验证（提交后）

`git status` 干净之后重跑 → **8 项全绿**（第 7 项不再红）。
这一条留待提交后当场跑，结果记在下面。
