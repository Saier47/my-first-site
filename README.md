## 怎么跑起来

### 方式一：起本地服务（推荐，截图/验收用这个）

在**项目文件夹里**打开终端，执行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器打开：

```
http://localhost:8000
```

看到页面就成功了。想停掉服务：回到终端按 `Ctrl + C`。

> 为什么不用双击打开：双击走的是 `file://` 协议，浏览器对本地文件有限制，
> 而且没法在地址栏里看到 `localhost`。起服务是最接近「真的在服务器上跑」的方式。
> 本项目是纯静态页面，所以一个 Python 自带的静态服务器就够，不需要装任何东西。

### 方式二：直接双击 `index.html`

也能用（纯静态页面没有跨域问题），但地址栏不是 `localhost`，且部分浏览器对
`file://` 下的本地存储有限制。**验收和截图请用方式一。**

**一条铁律：`localStorage` 只出现在 `store.js` 里。**

只重写 `store.js` 内部，函数签名不动，`app.js` 一行不改。

## 切真数据 / 假数据（Day 8）

页面默认用 `mock-data.js` 里的**假数据**渲染，好处是不管在哪个浏览器、
哪个网址打开，看到的都一样 —— 做界面和截图时不会被"本机有没有录过东西"干扰。

想切回**你自己的真实数据**：打开 `mock-data.js`，把第 32 行的开关改成 `'off'`：

```js
var DATA_SOURCE = 'off';   // 改成 'off' 就用 store.js 读 localStorage
```

`app.js` 一个字都不用改 —— 这就是「数据源可替换」的意思。

四种页面状态也可以用它逐个看：

| 开关值 | 看到什么 |
| --- | --- |
| `'normal'` | **有数据**（默认，交截图用这个） |
| `'loading'` | 一直停在**加载中**（骨架屏） |
| `'empty'` | **空状态**（引导语 + 添加按钮） |
| `'error'` | **出错状态**（说明 + 重试按钮） |
| `'off'` | 用真数据（localStorage） |

## 数据存在哪

存在**你自己这台设备**的浏览器里（localStorage），**不上传任何服务器**。

存储键名：`mfs:courses`（课程）、`mfs:ddls`（DDL）。

**代价（本期明知并接受）**：
- 清空浏览器数据 / 用无痕模式 → 数据会丢；
- 换设备、换浏览器 → 数据不通用。

这两条等接入云数据库之后解决。
