## 怎么跑起来

### ⭐ 最快的方式：直接打开公网地址

```
https://my-first-site-d0g3re4p71560e327-1500310885.tcloudbaseapp.com/index.html
```

打开就是**数据库里的真实数据** —— 不用起服务、不用装任何东西，
发给同学他也能直接打开（Day 20 起）。

> ⚠️ 会先弹一个腾讯云的「确定访问」提示页，点一下才能进。这是云开发对
> **未备案测试域名**的强制提醒，官方说明关不掉（详见 `day15-deploy.md` 第 5 节）。

### 方式二：起本地服务（改代码时用这个）

在**项目文件夹里**打开终端，执行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后浏览器打开 `http://localhost:8000`。

> ⚠️ 本地起的页面调的是**云端接口**（`store.js` 里的 `API_BASE` 是绝对地址）。
> 所以断网的话，本地页面也读不到数据 —— 这和以前本地存 localStorage 时不一样。

## 发布前检查（Day 25 起）

**改完代码、准备把链接发给别人验收之前，先跑一遍：**

```bash
bash scripts/preflight.sh
```

**8 项，每项都带实测值**（不是只甩一个 ✅ 给你）：

| # | 查什么 | 为什么值得查 |
|---|---|---|
| 1 | 公网页面能打开 | 基本盘 |
| 2 | 打开的是应用、不是腾讯云中间页 | **HTTP 200 也可能拿到那个提示页** |
| 3 | 接口活着 | 页面在 ≠ 数据在 |
| 4 | **线上前端 == 本地前端** ⭐ | **改了但忘了部署** —— 页面照样能开、接口照样通，只有专门比对才看得出来 |
| 5 | 仓库里没有密钥 | 用 `audit-secrets.py`（8 类规则 + git 全历史） |
| 6 | `.env` 被忽略 | 问 git 本人，而不是看 `.gitignore` 里写了没 |
| 7 | 工作区干净 | 有未提交的改动 = 线上跑的可能是个半成品 |
| 8 | 没有没推的提交 | 「我提交了」和「远端真的有」是两件事 |

退出码：`0` = 全绿可以发布；`1` = 有项没过。

> 🔑 **这个检查最大的风险是"假绿"。**
> 一个**永远输出 ✅** 的检查，和**真的全绿**，在屏幕上长得一模一样。
> 所以有两条硬要求：
> ① 每项都输出**实测值**（状态码 / 字节数 / 命中数）—— 光一个 ✅ 不算证据；
> ② **定期故意弄坏一项，确认它真的会红**
> （最简单的做法：改一行本地 `app.js` 但不部署 → 第 4 项必须红，还原后必须绿）。
>
> 📌 完整规则与判断标准见 `.workbuddy/skills/preflight-check/SKILL.md`。

## 页面怎么走（Day 13）

一共 **3 个视图**，靠**地址**切换 —— 改地址栏里 `#` 后面那段，页面不会重新加载。

```
一级：底部导航（2 个入口 —— PRD 第 2.2 节第 2 条要求「不许有第 3 个」）
 ├── #/week     一周视图（打开默认在这）
 └── #/courses  清单页（课程 + DDL + 筛选）

二级（从一周视图里「今天」那一列的列头点进去）
 └── #/today    今天视图
```

| 地址 | 看到什么 |
| --- | --- |
| `#/week` 或什么都不写 | 一周视图 —— 这周的固定课和 DDL 叠在 7 列时间轴上 |
| `#/courses` | 清单页 —— 课程按星期分组、DDL 按截止时间排 |
| `#/courses?q=高数` | 清单页 + 筛选「高数」（筛选词也写进地址，能分享、能后退） |
| `#/today` | 今天视图 —— 今天几节课、几个 DDL 到期、有没有欠着的 |

**为什么「今天」放在二级、不占底部导航？**
"底部只有 2 个入口"是 PRD 用来验证"没偷偷加回校园社交、空教室"的防线（打开页面数一数就知道）。
所以第三个视图做成**点进去的下一层**，靠面包屑「← 这一周」回来 —— 底部导航仍然是 2 个。

**顺带买到的好处**：地址驱动意味着浏览器**后退键能用**、刷新停在原地、链接能直接分享。

### 四种状态

每个视图都有四种样子。数据没到手时，切到哪个视图看到的都一样（不会出现"一周视图在转圈、清单页一片空白"）。

| 状态 | 怎么看 |
| --- | --- |
| 正常 | 直接打开 |
| 加载中 | 打开的一瞬间（约 0.6 秒）就是 |
| 空 | 地址加 `?src=empty`，如 `index.html?src=empty#/week` |
| 出错 | 地址加 `?src=error`（带「重试一次」按钮） |

> `?src=...` 要写在 `#` **前面**，这样切视图时它不会丢。
> 这是**验收通道**，只是把已有的 mock 开关挪到地址栏上，数据没有变。

## 真数据 / 假数据（Day 8 加 · 2026-09-30 改了默认值）

**默认走真数据** —— 从**云端数据库**读（Day 20 起；在此之前是读本机 localStorage）。

> ⚠️ **2026-09-30 改的默认值。** 以前默认开着假数据，后果是：
> **用户录的课只进内存、一刷新就没**，而保存时还会正常弹出「✓ 已保存」。
> 一个学生打开网页、录完自己的课、关掉再打开 —— 课全没了。
> 详见 `usability-checkup.md`。
> 现在假数据默认**关**，打开网页看到的就是真实数据。

假数据是拿来**演示 / 截图 / 看四种页面状态**的。用**地址参数**开启，不用改源码：

| 地址 | 看到什么 |
| --- | --- |
| 直接打开（不加参数） | **云端数据库里的真实数据** |
| `?src=normal` | 演示用的**假数据**（内容固定，换台电脑打开也一样） |
| `?src=empty` | **空状态**（引导语 + 添加按钮） |
| `?src=error` | **出错状态**（说明 + 重试按钮） |

例：`index.html?src=normal#/week`

> `?src=...` 要写在 `#` **前面**，这样切换视图时它不会丢。
> 「加载中」不用参数 —— 打开的一瞬间（约 0.6 秒）就是骨架屏。

`app.js` 一个字都不用改 —— 这就是「数据源可替换」的意思。
（`check-persist.js` 专门盯着"默认真数据"这条，谁要是把开关改回去，测试立刻变红。）
